# TOC Smithton Control

Mobile-friendly environmental and stock control dashboard for the Tasmanian Oyster Company Smithton operation.

Features:
- Manual salinity entry with configurable minimum/maximum limits.
- Smithton 7-day rainfall forecast using Open-Meteo.
- Configurable 24-hour and 7-day rainfall thresholds.
- Browser notifications when configured thresholds are exceeded.
- Installable PWA/service-worker foundation.
- Farm/site quick entry for Boomer Bay, Pittwater, LSP, Pipeclay and SCL.
- Local stock movement register.

Environmental thresholds are user-configured rather than hard-coded. Set them to the limits approved for the operation.

Salinity settings and stock movements are stored locally in the browser. Weather is retrieved from Open-Meteo.
